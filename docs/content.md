# Как править контент

Весь текст, картинки и состав страниц лежат в `src/data/site.json`. Вёрстка читает этот файл и рисует страницы. Чтобы поменять заголовок, абзац или слайд, правьте JSON и сохраните файл. При запущенном `npm run dev` страница обновится сама.

Картинки лежат в `src/assets`, по папкам. В JSON путь пишется без `src/`:

- проект — `assets/projects/<slug>/файл.png`, где `<slug>` совпадает с адресом кейса;
- страница — `assets/about/`, `assets/resume/`, `assets/experiments/`;
- имя, слово и иконки соцсетей — `assets/profile/`;
- стрелки и иконки кнопок — `assets/ui/`.

Общее устройство сайта описано в [README](../README.md).

## Два языка

Видимый текст записан парой:

```json
"title": {
  "en": "Projects",
  "ru": "Проекты"
}
```

Кнопка в шапке переключает, какую половину показывать. На английском сайте на ней написано `RU`, на русском — `EN`: это язык, на который она переключит. Подпись для скринридера — поле `ui.switchTo`, его на кнопке не видно.

Выбор запоминается в браузере. После перезагрузки остаётся последний язык. Чистый заход открывается по-английски.

Правите одну половину — вторая не меняется. Новый абзац или пункт добавляйте сразу с `en` и `ru`. Пустая строка в одной из половин ломает проверку `npm test`.

Обычная строка без пары показывается на обоих языках. Так и задумано для почты, года, путей к файлам и адресов страниц.

Внутри текста `\n` — перенос строки. В подписи подвала (`profile.tagline`) он виден как новая строка. В описании места работы (`resume.jobs[].body`) пустая строка `\n\n` разрезает текст на отдельные абзацы.

## Что на что влияет

| Кусок JSON | Где видно |
| --- | --- |
| `profile.name`, `profile.summary` | Имя и подзаголовок на главной, «Обо мне» и в резюме |
| `profile.avatar` | Фото над именем на этих трёх страницах. В меню оно не входит |
| `profile.email` | Кнопка копирования почты в подвале. Пока `scheduleUrl` пустой, сюда же ведут «Let’s chat» и «Schedule a call» |
| `profile.scheduleUrl` | Если вписать адрес, обе эти кнопки открывают его вместо письма |
| `profile.tagline`, `profile.copyright`, `profile.wordmark` | Левая колонка подвала |
| `profile.social` | Иконки в подвале. Пустой `href` — картинка без ссылки. Заполненный `href` — ссылка. `label` — подпись для скринридера |
| `ui.nav` | Пункты меню в шапке и в подвале. `label` — текст, `to` — адрес. Допустимые адреса: `/`, `/about`, `/resume`, `/experiments` |
| `ui.latestWork` | Кнопка «My latest work». Открывает проект, который стоит первым на главной |
| `ui.letsChat`, `ui.schedule`, `ui.copied` | Кнопка письма, ссылка «назначить звонок», надпись «скопировано» |
| `ui.linksTitle`, `ui.contactTitle` | Заголовки колонок подвала |
| `ui.metaLabels` | Подписи Role / Timeline / Team / Platform на странице кейса. Значения этих полей лежат в самом проекте, в `meta` |
| `ui.notFound`, `ui.backHome` | Страница по несуществующему адресу и кейс с неизвестным `slug` |
| `about` | Страница `/about` |
| `resume` | Страница `/resume` |
| `projects` | Карточки на главной и страницы кейсов `/case-studies/<slug>` |
| `experiments` | Страница `/experiments`. В меню её нет, пока пункт не добавлен в `ui.nav` |

Поля `ui.exploreMore`, `ui.menuOpen`, `ui.menuClose` и `defaultLocale` в файле есть, экран их не читает. То же с `client` у проекта: правка ничего не меняет на сайте.

## Проекты

Каждый объект в `projects` — одна работа.

`slug` становится адресом: `crm-platform-for-managing-room-bookings` открывается как `/case-studies/crm-platform-for-managing-room-bookings`. Смена `slug` ломает старую ссылку.

`year` — и год на карточке, и порядок. На главной сначала более поздний год. Если годы совпали, выше оказывается проект, который в JSON стоит ниже. Кнопка «My latest work» открывает верхний в этом порядке. Год пишите четырьмя цифрами, строкой: `"2025"`.

`title` и `summary` — заголовок и лид на странице кейса. `title` ещё и подпись карточки на главной.

`cover` — фон карточки на главной. `screens` — скриншоты поверх этого фона. На страницу кейса они не попадают. `"span": "full"` растягивает карточку на всю ширину сетки. Без этого поля карточка обычная.

`hero.screen` — картинка в шапке кейса. `hero.overlay`, если он есть, заменяет её. `hero.phone` добавляет рядом телефон.

`meta` — четыре факта под шапкой. Пустая строка прячет этот факт вместе с подписью. Подписи («Роль», «Период»…) берутся из `ui.metaLabels`, текст факта — из `meta` проекта.

`brief` — серая карточка-аккордеон. `title` — заголовок, `text` — строка в свёрнутом виде, `items` — блоки, которые раскрываются по клику. У каждого блока есть `title` и `text`.

## Секции кейса

`sections` идут по странице сверху вниз в том порядке, в каком стоят в массиве. У секции:

- `id` — якорь. `overview` даёт ссылку `#overview`. Меняйте его только вместе с пониманием, что старый якорь перестанет открываться.
- `nav` — пункт в липком меню кейса.
- `kicker` — красная надпись над секцией.
- `heading` — крупный заголовок. Пустую строку можно не писать: заголовка не будет.
- `paragraphs` — абзацы под заголовком.
- `insights` — блоки внутри секции: подзаголовок, абзацы, список и картинка.
- `hidden: true` — секция не рисуется и пропадает из меню кейса. Остальные секции остаются.

У блока `insights`:

- `heading` — подзаголовок. Пустая строка его скрывает.
- `paragraphs` — абзацы.
- `points` — список «заголовок + текст».
- `figure` — картинка или карусель под текстом.

## Картинка и карусель

Одна картинка:

```json
"figure": {
  "src": "assets/projects/crm-platform-for-managing-room-bookings/crm-dashboard.png",
  "alt": { "en": "CRM dashboard", "ru": "Дашборд CRM" }
}
```

`alt` на экран не выводится, его читает скринридер.

Несколько кадров — карусель. Стрелки появляются, когда в `slides` больше одного кадра. Один кадр стрелок не показывает. Крайние стрелки не зацикливают ленту.

```json
"figure": {
  "src": "assets/projects/crm-platform-for-managing-room-bookings/crm-booking-flow.png",
  "alt": { "en": "Booking flow analysis", "ru": "Анализ процесса бронирования" },
  "slides": [
    { "src": "assets/projects/crm-platform-for-managing-room-bookings/crm-booking-flow.png", "fit": "cover", "align": "left" },
    { "src": "assets/projects/crm-platform-for-managing-room-bookings/crm-structure.png", "fit": "contain" }
  ]
}
```

`fit`: `cover` заполняет рамку и обрезает края, `contain` вписывает картинку целиком. `align: "left"` прижимает кадр влево, без него кадр по центру. Эти два поля общие для обоих языков, их не оборачивают в `{ "en", "ru" }`.

`src` у самой `figure` нужен и при карусели: с него начинается показ, если массив `slides` пуст.

Новый файл кладёте в `src/assets` и ссылаетесь на него по имени. Файл, которого нет, на странице будет битой картинкой, а `npm test` упадёт.

## Страница «Обо мне» и резюме

`about.paragraphs` — абзацы рядом с портретом. `about.interests` — чипы: `label` это текст, `icon` это картинка. `about.values` — карточки «заголовок + текст». `about.path` — четыре шага внизу: картинка, `alt` и видимая подпись `caption`.

`resume.jobs` — места работы сверху вниз, как в массиве. `icon` — логотип. `resume.tools` — список инструментов, `iconCrop: true` обрезает иконку плотнее. `resume.skills` — чипы, просто массив строк. `resume.education` — блок учёбы, `lines` идут отдельными строками.

## Новая работа

Скопируйте один объект внутри `projects` и поправьте его.

1. Новый `slug` латиницей, без пробелов.
2. `year`, `title`, `summary`, `meta`, `brief`.
3. Свои файлы в `src/assets` и пути в `cover`, `screens`, `hero`, `figure`.
4. Секции с уникальными `id`.
5. У каждого нового текста обе половины, `en` и `ru`.

Проект появится на главной по своему году и откроется по `/case-studies/<slug>`. Новую страницу сайта одним JSON не добавить: адреса `/`, `/about`, `/resume`, `/experiments` зашиты в код.

## Если страница погасла после правки

JSON не прощает лишнюю или пропущенную запятую и незакрытую скобку. Верните последнюю правку или проверьте скобки вокруг изменённого куска. В консоли `npm run dev` будет строка с номером ошибки.

`npm test` проверяет три вещи: у каждой пары `{ "en", "ru" }` обе строки непустые, каждый путь `assets/...` указывает на существующий файл, имя и пункты меню совпадают с тем, что записано в `src/data/site.contract.test.ts`. Если меняете имя или подписи Projects / About / Resume, поправьте и этот тест.
